"I developed an end-to-end Infrastructure as Code automation project using Terraform, 
GitHub, Azure DevOps and Microsoft Azure. First, I configured my local development 
environment with Terraform, Git, Azure CLI and VS Code. Then I developed Terraform 
configuration files and pushed them to GitHub. I integrated the GitHub repository with 
Azure DevOps and configured Azure authentication using a Service Connection. I used an 
Agent Pool to execute Terraform commands. Finally, I designed a CI/CD workflow with 
Terraform Init, Validate, Plan, Manual Approval and Apply stages to automate Azure 
infrastructure provisioning. I also configured Azure Blob Storage as a remote Terraform 
state backend."
